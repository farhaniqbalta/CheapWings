# P5.1 Shared Rust Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One Rust crate holding CheapWings' money, itinerary fingerprint, ranking and Fli page decoder, used by the Python web backend (money first, via PyO3) and packaged for the iPad (via UniFFI), with both sides gated by one shared fixture file generated from the Python reference.

**Architecture:** Cargo workspace `core/` with three crates: `cheapwings-core` (pure logic, no I/O), `cheapwings-py` (PyO3 module `cheapwings_core`) and `cheapwings-ffi` (UniFFI static library for iOS). Networking and UI stay native: callers fetch bytes and pass text in. Python's `money.py` keeps its `Money`/`FXSnapshot` types and validation but delegates arithmetic to Rust.

**Tech Stack:** Rust 1.100, rust_decimal, sha2, serde_json (`arbitrary_precision`), PyO3 + maturin, UniFFI, Swift Package Manager, XCTest, Python 3.12/pytest.

**Spec:** [P5.06 owner decision](p5.06.md#owner-decision-2026-11-13-after-s5), [P5.05 analysis](p5.05.md) §3–§4. Proven prototypes to port from (do not import): `spikes/core-s5/rust/src/lib.rs`, `spikes/money-pyo3/src/lib.rs`, `spikes/fli-probe/Sources/FliProbe/{Tfs,Decode,Probe}.swift`.

## Global Constraints

- Crate versions pinned exactly: `rust_decimal = "=1.43.0"`, `uniffi = "=0.32.2"`, `pyo3 = "=0.30.1"`; `sha2 = "0.10"`; `serde_json = { version = "1", features = ["arbitrary_precision"] }`.
- No floats for money anywhere; values cross language boundaries as decimal **text**.
- Money semantics are Python's: unknown currency fails closed; FX rounds half-even to the quote currency's minor units and pads scale (`"12.30"`); a negative product that rounds to zero keeps its sign (`"-0.00"`, IDR `"-0"`).
- Fingerprint = SHA-256 hex of segments joined by `|`, each segment's fields joined by `,` in the order `ordinal, marketing, operating, flight, origin, destination, depart isoformat, arrive isoformat`, isoformat byte-identical to Python `datetime.isoformat()` for aware datetimes.
- Ranking order equals Python's stable `sorted` (ties keep input order).
- Rust does no networking and no file I/O in `cheapwings-core`.
- iOS: one Rust static library per app (only `cheapwings-ffi`); `IPHONEOS_DEPLOYMENT_TARGET=17.0`, `MACOSX_DEPLOYMENT_TARGET=13.0`; Swift package platforms `.iOS(.v17), .macOS(.v13)`; per-module header folder in the XCFramework.
- Build outputs (`core/target/`, XCFramework, generated bindings) are gitignored and rebuilt by script.
- No live provider requests in this phase. No provider payloads in fixtures (synthetic pages only).
- Backend suite gate: `.venv/bin/python -m pytest backend/tests -q` stays green (245 tests before this phase).

## Review Focus

1. Unknown currency through the Python API must still raise `UnknownCurrencyError` (not a bare `ValueError`) once Rust does the lookup — pinned in Task 4.
2. Prices with trailing zeros (`1234.50`) must survive the Fli decoder as `"1234.50"`, not `"1234.5"` or a float — pinned in Task 3.
3. Amounts beyond Python's 28-digit decimal context now go through Rust and stay exact (behaviour change from S4); the new behaviour must be pinned, not accidental — Task 4.
4. A Fli page with no `ds:1`, a traffic-block page, or more than 500 rows must return an error code, never panic across the FFI/PyO3 boundary — Task 3 and Task 5.
5. Importing the backend without the compiled `cheapwings_core` module must fail with an instruction to build it, not an opaque `ModuleNotFoundError` deep in a request — Task 4.
