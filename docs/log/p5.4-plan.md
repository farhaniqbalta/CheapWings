# P5.4 iPad Skiplagged Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Skiplagged as a second source on the iPad, next to Fli, so one search shows both sources' fares — honestly labelled, paced per source, saved and resumable per source.

**Architecture:** Skiplagged plugs into the P5.8 `SearchProvider` seam as `SkiplaggedSearchProvider`. Its networking is a small Swift MCP (JSON-RPC over HTTPS) client; its response parsing and USD→display-currency conversion live in the Rust core (exact decimals, Python-reference fixtures, reusable by the web in P5.7). The runner gains one paced **lane per provider** running side by side; work items become (provider, route/date); a provider-neutral offer replaces the Fli-only one; the store gains a provider column (schema v2 migration).

**Tech Stack:** Rust (`cheapwings-core`, `cheapwings-store`, UniFFI 0.32.2, `serde_json` exact numbers), Swift (CheapWingsKit, URLSession, SwiftUI), XCTest, Python reference for fixtures.

**Spec:** owner decision 2026-11-14 (P5.4 = Skiplagged only; OctoTrip deferred until further notice; minors to P6); [p5.05.md](p5.05.md) (Skiplagged GO from iPad: MCP over HTTPS, keep raw bytes for exact Decimal, USD + display-only FX, no segment identity); `backend/src/cheapwings/providers/skiplagged.py` + `rate_limit.py` (the reference behaviour); [p5.8-plan.md → Plugging in more providers](p5.8-plan.md#plugging-in-more-providers-p54-not-built-here) and the P5.8 review minors (retry-after outcome, neutral offer type); provider ledger in `WORK_LOG.md` (Skiplagged personal use only).

## Global Constraints

- Request = the web's: tool `sk_flights_search`, `origin`, `destination`, `departureDate`, `adults: 1`, `fareClass: "economy"`, `limit: 20`, `includeHiddenCity: false`, `includeVirtualInterlining: false`, `currency: <display currency>`. Endpoint `https://mcp.skiplagged.com/mcp`, no auth.
- Card validation = `normalize()`: departure/arrival airports and departure date must equal the query, else the route/date fails `schema_changed`; `layovers` a non-negative integer; deep link kept only if `https://skiplagged.com/...`.
- Money: original price is **USD** (`price.usdAmount`, exact decimal, never a float); comparable amount = `fx_convert(usd, rate, display)` only when `pricing.currency == display` and `rateAsOf` present (display-only FX, shown with its date); else the offer is "currency unresolved" (ranked after comparable offers, labelled). USD searches need no FX.
- Price evidence: indicative, hidden-city **no** (excluded by request), baggage/fees unknown — same as the web.
- Pacing: Skiplagged `ProviderPacing(interval: 3 s, maxInFlight: 3)` (web interval 3 s, C3); Fli unchanged (0.25 s × 6). Lanes run side by side.
- Skiplagged HTTP 429 / MCP rate-limit → **retry** that route/date after `Retry-After` (seconds or HTTP date; default 60 s), at most 3 attempts, then `failed("http_rate_limited")`; the Skiplagged lane waits, Fli continues. 401/403 → Skiplagged lane stops (`blocked`), Fli continues. Offline stops every lane. Cancel stops every lane.
- A Google stop still stops only the Fli lane and keeps the 30-minute Resume wait for Fli items; Skiplagged items resume at once.
- Old searches (P5.3–P5.8 stores, Fli only) open and resume after the schema v2 migration; existing rows become provider `fli`.
- Sources picker: Fli and Skiplagged, both on by default (as the web's default selection); at least one required.
- Personal-use terms (owner accepted 2026-11-09); no live provider requests by the implementer. The owner's device check is the first live iPad Skiplagged run.
- Keep Discover seams (docs/02) and the provider-neutral runner (no provider names in `PacedRunner`).

## Review Focus

1. Skiplagged returns 429 with `Retry-After: 30` mid-search → its lane pauses ~30 s and retries; Fli days keep arriving; after 3 limited attempts that day shows "rate limited" for Skiplagged only — Task 3.
2. Display currency IDR but Skiplagged sends no IDR rate → offers show the USD price, "not converted", ranked after IDR fares, never mixed into "Cheapest" — Task 1 + Task 4.
3. A P5.8 database (no provider column) is opened → migrated in place, last search restored, Resume still works — Task 3.
4. Fli is blocked by Google while Skiplagged is running → Fli lane stops (30-min wait), Skiplagged finishes, the date strip shows each day as searched only when both sources are done — Task 3.
5. MCP replies as SSE (`text/event-stream`) instead of JSON, or with a session-id header to echo → both parsed; the raw JSON number text is kept for exact money — Task 2.

**Interfaces:**
- `protocol MCPTransport: Sendable { func post(_ body: Data, sessionID: String?) async throws -> MCPReply }`, `MCPReply { status: Int, headers: [String: String], body: Data }`; `URLSessionMCPTransport` (ephemeral session, `Accept: application/json, text/event-stream`, 30 s timeout, 2 MB cap).
- `actor MCPClient { init(transport:); func callTool(_ name: String, arguments: [String: Any]) async throws -> Data /* raw tool JSON text */ }` — lazily `initialize` (protocolVersion `2025-11-25`, clientInfo `CheapWings`), keeps `Mcp-Session-Id`, sends `notifications/initialized`, then `tools/call`; parses JSON or SSE `data:` frames; returns the first text content that is a JSON object with `flights` (raw bytes, so the Rust parser sees exact numbers); re-initializes once on 404/session expiry.
