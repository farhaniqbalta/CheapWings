## What exists now

| Area | Change |
|---|---|
| Rust core | `skiplagged` module: port of `providers/skiplagged.py` `normalize()` (same checks and error codes, exact decimals from the raw MCP text, USD → display currency through the shared `fx_convert`, deep link kept only for https skiplagged.com, `stable_id` identical to Python); `skiplagged_tool_payload` picks the exact payload from a JSON-RPC reply (structured content, then a JSON text block; tool/RPC errors → `provider_unavailable`). Provider-neutral `SourceOffer` (Fli offers via `fli_source_offer`). |
| Store (schema v2) | Each row is a work item (provider × route/date); offers stored as `SourceOffer` JSON; per-provider stop reasons; in-place migration from v1 (old rows become Fli, old offers read back as Fli offers). |
| Swift | `MCPClient` (initialize → initialized → tools/call, session id kept and re-initialised once on expiry, JSON or SSE replies, raw text to Rust); `SkiplaggedSearchProvider` (same request as the web, pacing 3 s × 3, 429 → retry after `Retry-After` / HTTP date / 60 s, 401/403 → stop that source, offline → pause). Engine runs **one paced lane per source** side by side; an item's events are released together; retry-after pauses only that lane (≤ 3 attempts, then `http_rate_limited`); a source stop ends only its lane; offline/cancel end all. |
| Session | Work items, per-item checkpoints, per-source stops; Resume per source — a source that rate-limited/blocked waits 30 min, the others resume at once; pre-P5.4 searches resume as Fli. Date strip: a day is searched when every selected source finished it. |
| Ranking | By the comparable (display-currency) price; offers whose price could not be converted rank last and are never Cheapest. |
| App | Sources switches (Google Flights, Skiplagged; both on); outlined source label on every fare; Skiplagged rows show its airline names and the conversion note ("Converted from US$271 at 18108.7 (rate of 9 Nov)" or "Not converted"); Skiplagged details: departure, summary, arrival, "Open on Skiplagged"; stop messages name the source. |

## Rulings made during implementation

- Fixtures use the one recorded payload with structured content plus 18 synthetic cases; a
  "float price" case cannot occur from raw text (Python parses numbers as Decimal) and is dropped.
- `SourceOffer.minutes` added (door-to-door from Skiplagged's zoned times; Fli computes its own).
- Error codes follow Python exactly; the plan's `empty_payload` dropped (empty flights = no offers).
- Exact money across MCP: Swift extracts the JSON-RPC message and hands its raw text to Rust.
- MCP client tests use a scripted transport fake instead of URLProtocol.
- Skiplagged provider got `fetch` first and its `SearchProvider` conformance with the neutral offer.
- Store keeps `idx` as the global work-item index (provider column added by ALTER TABLE).
- Lanes emit `.item(i)` before an item's events through one actor; existing event cases kept.
- Overall stop = offline > first source stop > cancelled > finished; cooldown per source for any
  rate limit/block (so Skiplagged's own block also waits 30 min); resuming keeps the original
  stop time of a source still cooling down.
- Unconvertible offers are appended after the core's ranking and never marked Cheapest.
