## Rulings made during implementation

- Fixtures use the one recorded payload with structured content plus 18 synthetic cases; a
  "float price" case cannot occur from raw text (Python parses numbers as Decimal) and is dropped.
- `SourceOffer.minutes` added (door-to-door from Skiplagged's zoned times; Fli computes its own).
- Error codes follow Python exactly; the plan's `empty_payload` dropped (empty flights = no offers).
- Exact money across MCP: Swift extracts the JSON-RPC message and hands its raw text to Rust.
- MCP client tests use a scripted transport fake instead of URLProtocol.
- Skiplagged provider got `fetch` first and its `SearchProvider` conformance with the neutral offer.
- Store keeps `idx` as the global work-item index (provider column added by ALTER TABLE).
- Lanes emit `.item(i)` before an item's events through one actor; existing event cases kept.
- Overall stop = offline > first source stop > cancelled > finished; cooldown per source for any
  rate limit/block (so Skiplagged's own block also waits 30 min); resuming keeps the original
  stop time of a source still cooling down.
- Unconvertible offers are appended after the core's ranking and never marked Cheapest.

## Final review (fresh subagent, Opus)

0 Critical, 4 Important, 9 Minor. Fixed in one pass (Kit 98/98, twice):
- **Concurrent Skiplagged calls each ran the MCP handshake** (and a stale 404 could throw away a
  fresh session): one shared handshake task that every caller awaits, plus a session generation
  so only the first caller resets an expired session (`testConcurrentCallsShareOneHandshake`,
  `testExpiredSessionReinitializesOnceForConcurrentCalls` RED → GREEN).
- **Protocol version not negotiated**: requests now carry the version the server agreed in
  `initialize` (`testNegotiatedVersionIsSent` RED → GREEN).
- **Sustained 429s failed days for good and kept hitting Skiplagged**; a huge `Retry-After` slept
  silently: after 3 limited attempts, or a wait over 2 minutes, the source stops as rate-limited —
  its days stay pending and the 30-minute cooldown applies
  (`testSustainedRateLimitStopsTheLaneAndKeepsItemsPending`, `testLongRetryAfterStopsInsteadOfSleeping` RED → GREEN).
- **Date strip mixed currencies** (a USD-only day showed "271" beside "1.5M" with a tiny bar):
  bars and their scale use only display-currency prices; such a day reads "USD 271" with no bar
  (`DaySummary.lowestComparable` / `unconvertedCurrency`, `testUnconvertedOnlyDayIsLabelledNotMixedIntoTheStrip`; UI build-verified).

Deferred minors (P6): a retrying request does not re-check the lane's stop flag (one extra
request possible after another item's 403); installing an older build resets the store version
and the next open fails on "duplicate column" (history unavailable, searches still work);
per-provider stop times are not stored separately (cooldown counts from the last update, only ever
longer); the FX note cannot parse fractional-second rate dates (no date shown); Skiplagged time
parsing differs from Python `fromisoformat` in edge cases (+0530 offsets, junk, 31 Feb);
`stable_id` matches Python only for string ids; exponent-form prices kept as written; fixture gaps
(Z suffix, non-colon offsets, UTC/local date split, link userinfo/port, exponent, `layovers: 1.0`,
non-string ids); items for a source missing from the engine never finish (cannot happen in the app).
Reviewer-declined: Skiplagged's own block waiting 30 min (ruling); live server behaviour; generated
bindings; visual layout.
