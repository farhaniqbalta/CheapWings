## What exists now

| Path | Role |
|---|---|
| `core/cheapwings-core` `locations` | Rust port of `locations/catalog.py`: loads the shared `catalog.json` (15,656 airports/cities/countries, version `p410-2026-11-11.1`) with the same validation; accent-folded search ranked like Python; `airports_of`, curated Major resolution (10 places), airport lookup with IANA time zone. |
| `core/cheapwings-core` `fli` | `filter_offers(..., max_stops)` hides itineraries with more stops (reason `stops N > M`); `airport_changes` finds connections that switch airports (e.g. NRT → HND). |
| `cheapwings-ffi` | `LocationCatalog` object, `Location` / `MajorResolution` / `AirportChange` records, `CatalogError`; `fliFilterOffers(maxStops:)`; stored request gains `max_stops`, `origin_majors`, `destination_majors` (serde defaults: P5.3 rows still load). |
| `CheapWingsKit` | `AirportToken` / `AirportSelection` (stacked airports and Major places, union of codes, remove-an-airport expands a Major place, restore from storage); `SearchRequest.maxStops` + Major ids; `ItineraryInfo` (stops, per-leg and total minutes from airport time zones, layovers, airport changes; durations omitted when a zone is unknown). |
| `apps/ios/CheapWings` | Bundles the backend `catalog.json` (no copy). Airport picker sheet: cities and countries first with one-tap "Add N major", browse all airports of a place, airport toggles, selected tokens with removable airport chips; Max stops (Any / Nonstop / 1 / 2); flight rows show stops + total duration + airport-change warning; itinerary detail screen (flights, local times, durations, layovers, price caveats). Typed-code fallback if the catalog fails to load. |

## Picker UX (owner decision during the device check)

UX research (web P4.10 picker, Google Flights, Skyscanner/Kayak, iOS token fields) and owner
answers: Major airports are the primary path; one side may **stack several places** (Tokyo
Major + Osaka Major + CGK); removing one airport from a Major place **turns that place into
plain airport tokens** (no "customized Major" state). The web picker keeps its two-mode
P4.10 behaviour for now, so the two UIs differ.

## Rulings made during implementation

- `airport_changes` tested by Rust + Swift unit tests, not a Python fixture (no Python function).
- `metro_only_codes` not ported (web API check only).
- `fold()` maps ß/ẞ to "ss" explicitly (Python `casefold`); other casefold-only mappings not covered.
- `CatalogError` splits Python's "unknown location or mismatched type" into two codes.
- `Catalog::location(id)` added so restored Major places show their name.
- P5.3 compatibility pinned by a Rust serde test, not a Swift raw-row test.
- `Layover.toAirport`, `legMinutes`, `durationText` added for the detail screen.
- Picker redesigned on owner request (see above); stored Major fields became lists.
