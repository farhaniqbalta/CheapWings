## What exists now

| Area | Change |
|---|---|
| Offline | A lost connection (`URLError` not-connected / connection-lost / data-not-allowed / roaming-off) pauses the search as `StopReason.offline`; the unfinished route/dates stay pending (never marked failed) and Resume continues them once online, with no cooldown. Timeouts still fail only their route/date. `NetworkMonitor` (NWPathMonitor) blocks Search and Resume while offline with plain messages. |
| Picker | Rust `search_page(text, within, limit)` returns the first 50 plus the total ("N more matches"); folding now drops only combining class ≠ 0, exactly like Python (typed marks such as "Tokyoा" no longer match); a query over 100 characters shows the error, not "no matches". |
| Durations | Inconsistent leg times give "unknown", never a negative duration. |
| Design | Airfield-signage direction: sign yellow `#F5C400` only for the main action and "cheapest" (black text on it); IATA codes in SF Pro Expanded; system colours elsewhere; darker warning orange in light mode (system orange fails contrast on white). Search side: large route codes that open the picker, "Search 31 days". Results: a **date strip** (lowest fare per departure day, cheapest day(s) yellow, pending dashed, failed "—", tap to filter); flight rows with price first, Cheapest tag, airline line, flight numbers/layovers/date. Details: vertical timeline with an orange airport-change step that explains the risk. |
| Airline names | `contracts/airlines.json` (1,104 codes) generated by `scripts/gen_airlines.py` from the same fli `Airline` table the web provider uses; bundled. Rows and the timeline show an outlined code plate plus the name ("Garuda Indonesia and Korean Air", "GA 878, KE 2101"); unknown codes show the code only. Fli pages carry codes only. |
| Ties | Every day and every flight tied at the lowest fare (exact decimal amount, same currency) is highlighted, not just the first. |
| Accessibility | Flight row = one VoiceOver element (price, cheapest, stops, spoken duration, route, airline, date, warnings); "Add major airports" is a separate VoiceOver action on place rows; picker chips ≥ 44 pt; date strip columns labelled; rows stack at accessibility text sizes; route header and rows adapt to narrow widths. |
| Kit | `DaySummary` (per-date lowest/pending/failed/cheapest, pure, reusable by a future Discover screen), `SearchSession.planned` / `finished`, `AirlineNames`, `ItineraryInfo.spokenDuration`. |
