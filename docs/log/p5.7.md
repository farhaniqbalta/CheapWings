### Decisions and review

- Ruling: fingerprint adapters pass Python identity strings to the shared hash —
  preserves datetime ISO formatting, including fractional UTC offsets, without
  narrowing valid host fields to the iPad's timestamp representation.
- Ruling: exact ranking comparison is separate from fixed-precision money
  arithmetic — rounding or dropping valid candidates violates web behavior;
  direct boundary overhead is the cost of retaining exact source values.
- Independent review: no material findings; 5,006 seeded arbitrary-precision
  decimal cases also matched Python Decimal sorting. Retained public `fold()` as
  a wrapper and removed its duplicate Python implementation after review.
