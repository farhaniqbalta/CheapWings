## Checkpoint 3 — Fli and Skiplagged parsing

Based on merged checkpoint 2 (`434b9e7`). The web worker decodes Fli rows and
Skiplagged cards through PyO3. Fli shares page row collection with iPad. The web
record includes the source date/time arrays and the operator code, and Python
uses the pinned SDK model validation and name tables, then resolves airport
timezones. The Skiplagged web record carries the original source timestamps,
airport and card identifiers, decimal values, and link. Python constructs
the existing domain results, validates link hosts, and computes stable quote
IDs and FX evidence. The iPad continues using its existing offer representation
and filtering. Web Fli still rejects the entire payload on currency mismatch.

Frozen Python references generate the expected results independently of the
bindings. Complete-result comparisons cover decimal precision, source IDs and
names, codeshares, timezone offsets, fractional seconds, malformed records,
unpriced counts, mixed currency, invalid links, and partial results. Review
found an ordering difference when a later malformed Fli row followed an earlier
currency failure. The Rust decoder now preserves the position of the row error
so the earlier failure wins. A focused test covers that case.

P6 remains release and owner acceptance, including readable failure wording
and the deferred iPad items listed in [P5.4](p5.4.md). OctoTrip/swoop parsing
and scheduler migration remain deferred.

A local synthetic timing spot check used three runs of 100 normalizations per
adapter, reporting the fastest run per payload. A repeated 50-row Fli page
went from 2.55 ms in the frozen Python adapter to 4.03 ms with Rust extraction
and Python result construction. The recorded Skiplagged fixture went from
0.06 ms to 0.18 ms. These measurements cover local processing only.

## PR #22 decoder review

Fli reads wire positions once into lossless Rust rows, then projects them
for the web and iPad. The web retains whole-page currency rejection and iPad
retains candidate filtering. Web builds flight segments directly and uses
pinned code tables for canonical airport and carrier names. The Fli SDK
builds requests and serves as the independent test reference.

Skiplagged validates card route, date, price, stops, link host and page
completeness in Rust. Web reconstructs timestamp objects from the source text
and retains its FX and evidence policy. iPad derives its existing offer shape
from the same decoded records. Per-row errors preserve earlier host failures.

The approved native URLSession capture returned HTTP 200. The saved fixture
keeps 19 priced and 25 unpriced rows. It retains decoder-read positions and
replaces each opaque price token with only its ISO currency field. The frozen
Python decoder produced the expected results for all three test hosts. The
earlier single curl request failed during TLS and provided no data.
