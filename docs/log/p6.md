# P6 — Release acceptance

Baseline is merged main `648d104`, including P5.7 checkpoint 3 ([PR #22](https://github.com/farhaniqbalta/CheapWings/pull/22)). The checks use a separate worktree, a fresh backend environment, and disposable SQLite databases.

## Scope

Release acceptance covers repeatable setup, migration, restart and cancellation, conservative ranking and coverage, both Rust bindings, the web build, and the standalone iPad release build. The iPad results list now describes network, rate-limit, response, and unmatched-search failures in plain language. Stored error codes and scheduler behavior are unchanged.

The owner approved one Fli and one Skiplagged search with no retries. The canary records only public fare evidence and provider outcomes. Swoop and OctoTrip remain opt-in, with their previously documented limits. P7 is separate.

## Open release items

- Review Fli response-size headroom. The web cap is 4 MB, earlier measurements were about 3.3 MB, and the recorded P5.7 page was 2.32 MB. This sample does not establish the tail of the page-size distribution. The cap remains in force.
- Track the remaining iPad issues in [P5.4](p5.4.md), including downgrade compatibility, cooldown bookkeeping and the known retry stop edge. No store, scheduling, or provider default changes are part of this acceptance pass.
- Owner acceptance on a signed physical iPad remains separate from an unsigned Release build.

### Local transport diagnostics

The P6 process had no explicit proxy or custom CA environment variables,
and macOS reported no enabled system proxy. The pinned curl_cffi 0.17.0 uses
BoringSSL and offers HTTP/2 with the adapter's Chrome profile. A trusted
loopback TLS server advertising HTTP/1.1 returned HTTP 200 using those
client options. The loopback check proves basic local TLS negotiation and
HTTP exchange. It does not cover Google's TLS endpoint, public trust chain,
HTTP/2 negotiation, or the external network path. No live requests were made
during this diagnostic.
