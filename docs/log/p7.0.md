## Scope delta against earlier P7 docs

- `docs/02` said the shortlist feeds the existing `plan_search` cap. `plan_search` is a Cartesian origins × destinations × days expansion, so Discover gets its own `select_discovery_plan`, and `plan_search` stays Search-only.
- `docs/02` proposed a shared seeded random helper in Rust for Surprise Me. Surprise Me is deferred, so the helper is removed.
- Unpriced destination lists are not an evidence level. Adapters drop them and keep a count.
- No separate `planning` job stage. The snapshot, plan and enqueue happen in one transaction.
- Execution order (owner, 2026-11-21): Phase A (P7.0/P7.1) first; in Phase B, iPad/UniFFI before Python/PyO3.
